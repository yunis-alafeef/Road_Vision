# Road Vision 🚗🔍

نظام ذكاء اصطناعي احترافي لاكتشاف أضرار وتشققات الطرق من خلال الصور باستخدام تقنيات التعلم العميق (YOLOv8) مبني على بيئة Node.js للواجهة الخلفية مع واجهة مستخدم عصرية وأنيقة.

## ✨ المميزات (Features)

- **واجهة مستخدم عصرية (Modern UI):** تصميم أنيق مبني على الـ Glassmorphism يدعم الوضع المظلم ويسهل استخدامه.
- **رفع الصور بسهولة:** دعم السحب والإفلات (Drag and Drop) لرفع صور الطرق المراد فحصها.
- **تحليل دقيق وسريع:** الاتصال بواجهة برمجة تطبيقات (API) تعتمد على نموذج `YOLOv8` المُدرّب مسبقاً لاستخراج الأضرار، رسم المربعات حولها (Bounding Boxes)، وإظهار نسبة الثقة.
- **خادم Node.js متكامل:** تطبيق Express.js خفيف وسريع لمعالجة الطلبات وإدارة الملفات.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الواجهة الأمامية (Frontend):** HTML5, Vanilla CSS3, Vanilla JS.
- **الخادم (Backend):** Node.js, Express.js, Multer.
- **الذكاء الاصطناعي (AI/ML):** Python, Ultralytics YOLO, OpenCV.

## 🚀 طريقة التشغيل (Getting Started)

### المتطلبات المسبقة:
1. تثبيت **Node.js**.
2. تثبيت **Python 3.8+**.

### خطوات التثبيت:

1. **استنساخ المستودع (Clone the repository):**
   ```bash
   git clone https://github.com/yunis-alafeef/Road_Vision.git
   cd Road_Vision
   ```

2. **تثبيت حزم Node.js:**
   ```bash
   npm install
   ```

3. **تثبيت حزم Python للذكاء الاصطناعي:**
   ```bash
   pip install -r requirements.txt
   ```

4. **تشغيل الخادم:**
   ```bash
   npm start
   ```

5. **استخدام النظام:**
   - افتح المتصفح على الرابط: `http://localhost:3000`
   - قم برفع صورة طريق لتبدأ عملية الفحص والاكتشاف.
